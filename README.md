# 五代十国·群雄自决实验

这是一个独立实验项目：以五代十国为历史背景，玩家扮演赵匡胤，但世界中的其他角色并不等待玩家指令。

## 核心实验

NPC拥有：
- 性格：谨慎、冒险、贪婪、重义、多疑、野心等
- 能力与资源
- 忠诚、恐惧、威望、关系
- 当前目标与长期欲望
- 对世界信息的认知

每一回合 NPC 根据自身性格、关系、资源、风险和世界局势自主选择行动。

玩家可以影响人物，但不能把所有人物变成按钮式工具人。

## 第一阶段

先做一个无需后端、打开浏览器即可玩的模拟原型：

1. 五代十国局势面板
2. NPC 人物面板
3. NPC 性格与隐藏动机
4. 世界自动推进
5. NPC 自主决策
6. 决策日志/天下纪事
7. 玩家干预
8. 相同局势下，不同性格产生不同结果

后续再加入城池、军队、粮道、将领、战争和更复杂的政治关系。

## 启动

直接打开 `index.html` 即可。
